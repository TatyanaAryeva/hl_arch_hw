 - Запустите скрипт `start.sh` из корня проекта

### REST API

#### Register user

`POST /api/user/register`

Параметры тела запроса:

- `username`
  - длина от 3 до 20 символов
  - допустимые символы: латинские буквы в любом регистре, цифры, `_`
  - уникальное (двух пользователей с одним `username` быть не может)
- `password`
  - длина от 6 до 12 символов
  - допустимые символы: латинские буквы в любом регистре, цифры, спецсимволы `! @ # $ % & * + -`
- `name`
  - длина от 2 до 50 символов
  - допустимые символы: латинские и русские буквы в любом регистре
- `lastName`
  - длина от 2 до 50 символов
  - допустимые символы: латинские и русские буквы в любом регистре
- `dateOfBirth`
  - дата рождения в формате ДД.MM.ГГГГ
- `gender`
  - допустимые значения MALE, FEMALE
- `hobbies`
  - длина от 0 до 125 символов
  - допустимые символы: латинские и русские буквы в любом регистре, цифры, пробел, знаки пунктуации
- `city`
  - длина от 2 до 40 символов
  - допустимые символы: латинские и русские буквы в любом регистре, пробел, дефис

Все параметры являются обязательными.
Ответ: идентификатор зарегистрированного пользователя

#### Login

`POST /api/user/login`

Параметры тела запроса:

- username
  - пользователь с таким `username` должен быть зарегистрирован
- password

#### Get user

`GET /api/user/{id}`

Поля `username` и `password` не возвращаются.

#### Search user

`GET /api/user/search`

Параметры запроса:

- `namePrefix`
- `lastNamePrefix`
